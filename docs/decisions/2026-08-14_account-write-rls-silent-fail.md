# 닉네임 변경·관리자 계정 삭제가 조용히 실패하던 문제

**날짜**: 2026-08-14
**관련 파일**: repository.ts, nickname/route.ts, admin/users/[id]/route.ts

## What — 무엇이 달라졌나
닉네임을 바꾸려 하면 "계정을 찾을 수 없어요"가 떴다 — 로그인 방식(닉네임·구글 둘 다)과
무관하게 아무도 닉네임을 바꿀 수 없었다. 운영자 콘솔에서 계정을 삭제해도 실제로는
지워지지 않고 같은 "계정을 찾을 수 없습니다" 오류만 났다. 둘 다 정상 동작하도록 고쳤다.

## Why — 왜 필요했나
구글 계정으로 가입하면 처음엔 이메일에서 딴 닉네임이 자동으로 붙는데, 그걸 공개
리뷰·방문기록에 그대로 노출하고 싶어하지 않는 사용자가 있어 닉네임 변경 기능을 넣었지만
실제로는 항상 실패해서 아무도 못 썼다. 운영자 계정 삭제도 같은 이유로 눌러도 아무 일도
안 일어나는 상태였다.

## 판단 근거
사용자에게는 "계정이 없다"는 잘못된 오류로 보였지만 실제로는 계정이 멀쩡히 있는데
저장 자체가 조용히 안 먹히던 것이었다 — 이런 오탐은 사용자가 재시도해도 절대 해결되지
않고 혼란만 키우므로, 에러 메시지를 다듬는 대신 저장이 실제로 되게 만드는 쪽을 택했다.
