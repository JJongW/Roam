# 브랜드 에셋

_2026-08-15 생성 · 원본 `public/logo.svg`(1MB 래스터)를 벡터로 트레이스해 전 에셋을 여기서 파생시켰다._

## 마크 벡터화

- 원본은 1254×1254 PNG를 SVG로 감싼 **1,045KB** 파일이었다 (C2PA 메타데이터 포함).
- 마칭스퀘어 컨투어 추출 → RDP 단순화 → Catmull-Rom → 3차 베지어 변환.
- 결과 **8KB**, 원본 대비 **IoU 0.983**. 128배 작고 무한 확대 가능.
- 서브패스 3개(머리 점 / 몸통 / R 카운터)를 하나의 `<path>`에 `fill-rule="evenodd"`로 묶어야 카운터(가운데 구멍)가 뚫린다. 분리하면 구멍이 메워진다.

## 아이콘 배색 — 왜 인디고인가

두 안을 만들었다.

- **채택 · 인디고 배경 + 크림 마크** — `theme_color`가 이미 `#4f46e5`라 스플래시·주소창과 이어진다. 홈 화면의 다른 아이콘 사이에서 눈에 띈다. maskable 블리드 색이 자연스럽다.
- 대안 · 크림 배경 + 잉크 마크 — 원본 아트워크 그대로. 에디토리얼하고 차분하지만, 홈 화면에서 흰 타일로 묻힌다.

바꾸려면 `docs/brand/assets/alt/icons-cream/`의 파일로 교체하고 `icon.svg`의 배경색만 바꾸면 된다.

## 알아둘 것

- **16px에서는 디테일이 뭉갠다.** 마크가 아니라 인디고 타일로 읽힌다 — 정상이고 의도다. 24px부터 형태가 살아난다.
- `*_clear.mov` 41MB가 아직 `public/`에 있다. 서빙되지 않으니 밖으로 빼야 한다.
- 보일러플레이트 `next.svg`·`vercel.svg`·`file.svg`·`globe.svg`·`window.svg`와 197B `public/icon.svg`는 삭제 대상.
- 재생성 스크립트는 이 세션에서 만든 것이고 레포에 남기지 않았다. 마크가 바뀌면 트레이스부터 다시 해야 한다.
