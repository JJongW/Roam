# admin 폼 라벨이 입력칸과 연결 안 되던 문제

**날짜**: 2026-08-14
**관련 파일**: exhibition-manager.tsx, event-manager.tsx, booth-manager.tsx

## What — 무엇이 달라졌나
전시·이벤트·부스 관리 화면의 입력 폼에서, 항목 이름(라벨)을 클릭해도 옆 입력칸에
포커스가 가지 않고 스크린리더도 라벨을 읽어주지 않던 문제를 고쳤다. 세 관리 화면
모두에 있던 동일한 문제였다.

## Why — 왜 필요했나
겉보기엔 라벨과 입력칸이 나란히 붙어 있어 눈으로 보기엔 멀쩡했지만, 실제로는
서로 연결돼 있지 않았다. 마우스로 입력칸을 정확히 클릭해야만 입력할 수 있었고,
보조기기(스크린리더)를 쓰는 운영자에게는 이 폼들이 사실상 무엇을 입력하는
칸인지 알 수 없는 상태였다.

## 판단 근거
세 화면이 같은 라벨 컴포넌트를 각자 복사해 쓰고 있어 문제도 똑같이 반복돼 있었다.
화면마다 따로 고치는 대신 공통 컴포넌트 수준에서 한 번에 고쳐, 앞으로 같은 패턴으로
폼을 추가해도 자동으로 연결되게 했다.
