# 관리자 준비 표시 정렬, 초안 검수 박람회별 줄 (2026-11-28)

## 1. 다가오는 박람회 준비 표시
- Ted: "이거 왜 세로가 안맞아? 행사등록, 브랜드쪽 앞이 안맞잖아".
- 원인: 네 표시가 `flex-wrap`이라 둘째 칸 시작이 첫째 칸 글자 길이를 따라갔다. 바깥 그리드 마지막 열이 `auto`(알약 글자 길이)라
  박람회마다 표시 열 시작도 달랐다. 빈 원 아이콘(size-3)이 체크(size-3.5)보다 작아 글자 시작도 2px 어긋났다.
- 고침: 네 표시를 `grid-cols-2`로, 바깥 마지막 열을 `minmax(0,1fr)`로, 아이콘은 같은 크기 상자(size-3.5)에 넣었다.
- 버린 안: 첫 열 폭을 고정값으로 주기. 임의값이 늘고 "파일 기준 브랜드 242" 같은 긴 라벨에서 잘린다.

## 2. 초안 검수 대기 9건인데 눌러도 안 보임
- 운영 읽기(2026-11-28): 9건은 전부 "직접 조사"(재조사 판정)였다. 카페쇼 2026 8건, SIF 2026 1건, 둘 다 끝난 박람회. 사람이 볼 초안(forHuman)은 0건.
- 홈은 모든 박람회를 더해 셌고, 카드 머리를 누르면 화면은 쿠키나 오늘 기준으로 고른 박람회 하나(그날 SDF 2026, 0건)만 보였다.
  박람회마다 쓰는 함수(`enrichmentQueue`)는 같았지만 범위가 달랐다.
- 고침: `enrichmentQueueByFair`(lib/admin/queues.ts) 하나를 홈 카드와 초안 검수 화면 맨 위 "박람회별 남은 건수" 줄이 같이 쓴다.
  어느 박람회로 들어가도 홈 숫자가 박람회별로 보이고, 누르면 그 박람회를 고른다. 테스트 `today-load.test.ts`.
- 버린 안: 카드 머리 링크를 건수 많은 박람회로 보내기. 박람회가 둘 이상이면 나머지가 다시 안 보인다.
- 미정: 끝난 박람회의 초안을 홈에서 셀지(데이터 이슈 큐는 끝난 박람회를 뺀다). 직접 조사만 있을 때 카드가 "0건 직접 조사 9"로 보이는 표기.
