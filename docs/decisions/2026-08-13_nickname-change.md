# 닉네임 변경 기능

**날짜**: 2026-08-13
**관련 파일**: brain-sheet.tsx, nickname API

## What — 무엇이 달라졌나
내 취향 화면(닉네임을 눌러 여는 화면)에서 닉네임을 언제든 직접 바꿀 수 있다.

## Why — 왜 필요했나
Google 계정으로 로그인하면 가입할 때 자동으로 이름이나 이메일 앞부분에서 딴 닉네임이 붙는다. 그 닉네임이 리뷰나 방문 기록처럼 다른 사람도 볼 수 있는 자리에 그대로 노출돼, 사실상 실명이 공개되는 셈이었다.

## 판단 근거
개인정보 노출은 사용자가 스스로 통제할 수 있어야 한다. 자동으로 붙은 이름을 그대로 두지 않고 언제든 원하는 이름으로 바꿀 수 있게 해, 실명을 공개하고 싶지 않은 사용자를 보호한다.
