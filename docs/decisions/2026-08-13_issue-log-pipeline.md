# 오류/로그 파이프라인 정비

**날짜**: 2026-08-13
**관련 파일**: admin 오류/이슈 화면, issue_log 관련 코드 전반

## What — 무엇이 달라졌나
관리자 콘솔의 "오류 로그" 화면이 실제로 터지는 문제를 훨씬 더 많이 잡아 보여준다. 같은 오류가 반복되면 한 줄로 묶여 몇 번 발생했는지 보이고, 어떤 기능에서 난 오류인지, 어떤 기기·어느 나라/도시에서 발생했는지도 함께 보인다. 30일 지난 로그는 버튼 하나로 정리할 수 있다.

## Why — 왜 필요했나
지금까지는 앱 안에서 처리(핸들링)된 오류의 상당수가 관리자에게 전혀 보이지 않고 조용히 사라졌다 — 실제로 무슨 문제가 생기고 있는지 운영자가 알 방법이 없었다. 오류가 보이더라도 언제·어디서·누구에게·몇 번이나 일어났는지 알 수 없어 실제로 대응하기 어려웠고, 로그가 끝없이 쌓이기만 하고 정리할 방법도 없었다.

## 판단 근거
문제를 발견하는 것과 문제를 "고칠 수 있게" 보여주는 것은 다르다. 오류 하나하나를 따로 보여주는 대신 반복 횟수로 묶고, 기기·위치·기능 같은 맥락 정보를 같이 주는 쪽이 실제 운영 판단에 도움이 된다. 개인정보(이메일·인증 토큰 등)는 자동으로 가려지게 해서, 더 많은 정보를 보여주는 대신 사용자 프라이버시가 새는 일이 없게 했다.
