## 한 장 요약

**Roam** — 지금까지 파악한 네 취향으로 전시 부스를 골라 제안하고,
네 반응에 따라 계속 맞춰가는 **관람 동행자**.

> **반응할수록 정확해져**

### 출발점 — 비대칭

로미가 미리 아는 건 **전시**다. 로미가 미리 모르는 건 **너**다.
그래서 추천은 정답이 아니라 가설이고, 네가 반응하면 갱신된다. **이 루프가 제품이다.**

### 두 개의 판단

| | 누가 | 무엇을 |
|---|---|---|
| 1차 | **로미** | "이게 너한테 맞을 것 같다" — 가설. 틀리면 배운다 |
| 2차 | **사용자** | "갈지 말지" — 결정. 로미는 개입하지 않는다 |

로미가 1차 판단을 안 하면 그냥 부스 목록이다. 2차 판단까지 하면 명령이 된다.

### 문제 — 3단

```
1  규모   COEX 한 층, 킨텍스 한 홀. 부스 300개, 내 시간 네 시간.
          지도를 받아도 어디부터 봐야 하는지는 아무도 안 알려준다.
2  판단   어려운 건 걷는 게 아니라 고르는 것. 업종 한 줄 보고 300번 판단해야 한다.
3  기억   전시는 반복되는데 경험은 누적되지 않는다.
```

### 로미

이 전시를 **먼저 한 바퀴 돌고 온 친구**. 전문가가 아니라 먼저 본 사람이라서,
아는 건 말해주고 모르는 건 모른다고 한다. 성별도 나이도 없고, 몸은 걷는 R 글리프,
**모션이 표정**이다. 틀리면 부스를 깎지 않고 자기가 가져간다.

### 목소리 — 어기면 안 되는 5

```
1  반말 따뜻체        화자가 로미면 반말. 존댓말은 메타데이터·약관·어드민 세 곳뿐
2  한 호흡            길면 안 읽힌다
3  1인칭 발화          "추천 결과" 아니라 "내가 골라둔 곳"
4  과장·영업 금지      최고·놓치면 후회·느낌표 남발 X
5  명령 금지          사실 + 이유까지. 결정은 넘긴다
```

### Roam이 아닌 것

동선 생성기 · 내비게이션 · 정보 안내기 · 챗봇 · 성취 대시보드 · 특정 전시 전용 앱.

## 이 문서가 이긴다

브랜드북과 다른 문서가 어긋나면 브랜드북이 이긴다.
기계로 검사 가능한 규칙은 **`src/lib/i18n/brand-voice.test.ts`가 강제**한다 — 어기면 `npm test`가 깨진다.
규칙을 바꿔야 하면 브랜드북을 먼저 고치고, 그 근거로 테스트를 고친다.

특히 아래는 **폐기됐다.**

| 폐기 | 대체 |
|---|---|
| `끌림 / 나중에 / 별로 / 이미 봄` | `꼭 갈래·끌려·패스` / `좋았어·그냥그랬어·아니었어` |
| `ai-companion-ux-writing-patterns.md`의 존댓말 로그인 카피 | 반말 |
| 같은 문서의 `코스`·`이동 12분→5분` 동선/효율 카피 | 폐기 |
| `Roam — Exhibition Navigator` | `Roam` |
| 루트 `README.md`의 "without creating an account" · "turn-by-turn navigation" | 로그인 필수 · 피드 중심 |
