# 브랜드 줄 설명을 로그인 여부로 나눈다 (UI 23 이어서)

_2026-11-24 · 원천 결정: `../Roam-design/docs/decisions/2026-11-24_부스-상세-하트-하나.md` · 앞 기록: `2026-11-24_부스-하트가-브랜드도.md`_

## 결정 (Ted)

- "로그인 전 문구를 따로 나눠야지". 부스 상세 브랜드 줄 설명을 로그인 여부로 가른다.
  - 로그인한 분: "부스 하트를 남기면 이 브랜드의 다음 박람회 참가도 알려 드려요"(그대로)
  - 로그인 전: "로그인하면 다음 박람회 소식을 알려 드려요"
- 브랜드 알림은 로그인한 분만 받는다(11-17). 로그인 전에 "알려 드려요"를 그대로 보이면 지키지 못할 약속이 된다(브랜드 규칙 §4).

## 구현

- `src/lib/copy/v1.ts`에 `system.brandRowLoggedOut`을 더했다. #220에서 지운 옛 `brandRowLoggedOut`
  ("로그인하시면 브랜드 하트가 계정에도 남아요")는 문장이 달라 같은 이름에 새 문장을 넣었다.
- `components/booth-v2/brand-row.tsx`는 아래 바(`booth-actions.tsx`)와 같이 `useAuthStore((s) => !!s.user)`로 로그인을 읽는다.
- 줄은 여전히 누를 곳이 없다. 로그인 단추나 새 흐름은 Figma에 없어 만들지 않았다.

## 버린 안

- 로그인 전에도 한 문장: 로그인 전 사용자에게 받을 수 없는 알림을 약속한다.
- 줄에 로그인 단추를 붙이기: Figma UI 23 Q1 C에 없다. 로그인 권하기는 아래 바 하트의 스낵바(5-02)가 이미 맡는다.
