# 인기 부스 차트 — 조회 0일 때 빈 상태 추가

**날짜**: 2026-08-17
**관련 파일**: popular-chart.tsx

## What — 무엇이 달라졌나
관리자 분석 화면 "인기 부스" 카드가 조회 데이터가 하나도 없을 때 텅 빈 축만
보이던 것을, "아직 조회 데이터가 없어요" 안내로 바꿨다. 옆 "방문 흐름" 카드와
같은 빈 상태 톤.

## Why — 왜 필요했나
외부 UX 감사와 실제 브라우저 확인에서 "인기 부스" 차트가 고장난 것처럼 보인다는
지적이 나왔다. DOM을 직접 까본 결과 실제 원인은 폰트 크기 버그가 아니라(라벨
전부 font-size 12로 동일 — 긴 이름이 좁은 축 칸에서 줄바꿈되며 생긴 착시였음),
`Bar dataKey="views"`가 조회수 0에서 길이 0이 되어 막대 도형 자체를 안 그리는
것이었다(`recharts-bar-rectangle`·`path` 0개 확인). 축 라벨만 남아 빈 화면처럼
보였다.

## 판단 근거
가짜 인기도를 채워 보여주는 대신(이미 CLAUDE.md에 문서화된 설계 원칙 —
"정적 popularity 가산을 뺐다, 실제 조회 없으면 정직하게 0으로 보인다"), 데이터가
없다는 사실 자체를 명확히 알리는 쪽을 택했다. 바로 옆 "방문 흐름" 카드가 이미
같은 상황(집계 0건)에 `EmptyState`를 쓰고 있어서, 그 패턴을 그대로 재사용해
화면 전체의 빈 상태 톤을 일관되게 유지했다.
