# 지도 가로화면 잘림 · 가장자리 부스 접근성 · 검색창 확대 문제

**날짜**: 2026-08-13
**관련 파일**: map-view.tsx, exhibition-map.tsx, booth-search.tsx

## What — 무엇이 달라졌나
휴대폰을 가로로 돌려 지도를 볼 때 화면 양옆에 크게 남던 빈 공간이 사라지고 지도가 화면을 꽉 채운다. 지도 가장자리에 있는 부스도 화면 중앙 정도까지 끌어와 볼 수 있게 됐다. 전시 홈에서 검색창을 누를 때 화면이 확 커지던 것도 사라졌다.

## Why — 왜 필요했나
가로화면에서 지도를 보면 실제 화면 너비를 다 못 쓰고 좁은 세로 화면 폭만큼만 지도가 나와 크게 잘려 보였다. 또 지도 맨 끝(위·아래·좌·우)에 있는 부스는 화면 경계에 딱 붙어서 누르기도 전체를 보기도 어려웠다. 검색창은 누르자마자 화면이 확대돼 버려 사용성이 떨어졌다.

## 판단 근거
가로화면은 이미 다른 화면들에서 지원하는 기능인데 지도만 빠져 있었다 — 다른 화면과 일관되게 맞췄다. 지도 가장자리 접근성은 실제 사용 중 부스를 누르지 못하는 문제로 이어지므로, 화면 경계까지만 허용하던 제한을 풀어 화면 중앙까지는 끌어올 수 있게 했다.
