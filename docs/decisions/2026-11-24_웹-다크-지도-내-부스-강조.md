# 웹 다크 지도: A + 내 부스 강조 (UI 22)

_2026-11-24 · 원천 결정 Roam-design `docs/decisions/2026-11-24_다크-지도-내-부스-강조.md`(PR #59) · iOS Roam-ios PR #230_

## What

방문객 지도(v2) 색만 바꾼다. 화면, 흐름, 크기는 그대로다.

- 토큰을 Roam-design `fa7cbec`(PR #59 브랜치 커밋)에서 받았다(`npm run tokens:sync -- --commit fa7cbec…`).
- 홀 바닥: `bg-layer-default` → `map-floor`(지도 화면과 불러오는 중 뼈대 둘 다). 화면 바탕 토큰을 올리면 지도 밖 화면까지 바뀌어서 지도 전용 토큰이 따로 생겼다.
- 내 칸 = 하트를 남긴 칸 + 다녀온 칸. `map-booth-mine`으로 칠하고 이름, 하트, 체크는 `map-label-mine`, `map-heart-mine`, `map-check-mine`. 고른 칸과 편의시설 칸은 그대로(iOS `isMine`과 같은 기준).
- 보통 칸, 이름, 편의시설 칸은 같은 토큰 이름 그대로이고 다크 값만 #59에서 바뀌었다.

## Why

Ted가 11-23 TestFlight 다크 화면에서 "부스가 죄다 회색"이라고 했고, 11-24 캡처를 보고 "A + 내 부스 강조가 맞는 듯"으로 골랐다. 웹도 같은 토큰으로 맞춘다.

## 라이트에서 달라지는 것

토큰 이름을 iOS와 맞추면서 라이트에서 두 군데가 조금 바뀐다(값은 iOS 라이트와 같아진다).

- 다녀온 칸 체크: `fg-neutral-muted`(#555d6d) → `map-check-mine`(#1a1c20)
- 하트 칸 이름: `fg-neutral`(#1a1c20) → `map-label-mine`(#2a3038, 보통 칸 이름과 같은 값)

나머지(바닥, 칸, 하트, 이름)는 라이트 값이 같다.

## 웹에 없는 것

`map-wall`, `map-blocked`는 웹이 그리지 않는다(웹 도면에 벽 선과 막힌 면을 그리는 층이 없다). 새로 그리는 건 이 작업 범위 밖이라 두었다.

## 남은 것

- Roam-design #59가 머지되면 `src/styles/v2/source.json`의 고정 커밋(지금 `fa7cbec`)을 master 머지 커밋으로 바꾸고 `npm run tokens:sync -- --commit <머지 커밋>`을 돌린다.
