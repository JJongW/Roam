# 부스 판단 버튼 새로고침 깜빡임/에러 수정

**날짜**: 2026-08-26
**관련 파일**: judgment-bar.tsx

## What — 무엇이 달라졌나
지도·부스상세에서 이미 반응(꼭 갈래·끌려·패스 또는 좋았어·그냥그랬어·아니었어)을 남긴 부스를 다시 열었을 때, 화면이 깨지거나 콘솔에 에러가 뜨던 문제를 없앴다. 사용자에게는 버튼이 뜨는 순간이 한 프레임 정도 살짝 늦게 채워지는 정도로만 보인다.

## Why — 왜 필요했나
재방문자가 이미 판단을 남긴 부스를 지도나 부스상세에서 새로고침·직접 진입으로 다시 열 때마다, 브라우저가 저장해둔 내 판단과 서버가 처음 그려준 화면이 서로 달라서 화면이 깨지는 현상(React 에러 418)이 발생했다. 판단을 많이 남길수록, 재방문할수록 더 자주 겪는 문제였다.

## 판단 근거
가장 자주 쓰이는 재방문 흐름(이미 반응한 부스 다시 보기)에서 발생하는 에러라 우선순위를 높여 바로 고쳤다. 같은 종류의 문제를 이미 다크모드 토글에서 겪고 고쳐둔 전례가 있어, 그때 검증된 동일한 방식을 그대로 적용해 리스크 없이 빠르게 해결했다.
