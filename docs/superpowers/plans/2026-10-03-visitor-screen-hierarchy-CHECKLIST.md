## 순서가 중요하다

`1 → 2`가 먼저다. 타입이 확정되지 않으면 `5`의 높이 계산이 틀어진다.
`3 → 5`, `6 → 7`은 의존 관계다. `8`은 마지막(운영 dry-run이 필요).

```
Task 1 ─┬─ Task 2
        │
Task 3 ─┼─ Task 5 ◄── Task 4
        │
Task 6 ─┴─ Task 7 ─── Task 8
```

## 태스크

- [ ] **1. 문장용 타입 유틸** `.type-body` 16/26 · `.type-body-lg` 17/27 + 행간 가드 테스트
- [ ] **2. 피드·전시 카드 산문 교체** 12px 문장 제거 · 부스명 20px · `line-clamp` 2→3
- [ ] **3. 유틸리티 행** 지도·메모·검색 3칸, 터치 44 유지, 카드 껍데기 제거
- [ ] **4. `primaryAction`** 상태 → 유일한 CTA (순수 함수 + 6케이스 테스트)
- [ ] **5. 전시 화면 재배치** 포스터 208→120 · 메타 스크림 흡수 · 진행 비트 · `pb-28` 토큰화
- [ ] **6. 전시 카드 상태별 형태** 진행 중만 카드, 예정·종료는 행 · 추천 배지는 진행 중만
- [ ] **7. 홈 재배치** 마스코트 128px 제거 · 로그인 배너 전시 아래로 · 지난 전시 기본 접힘
- [ ] **8. 큐레이션 신호** 부스 수 · 로미 준비도 · 남은 일수 (운영 dry-run 필수)

## 완료 조건 (390 × 844 실측)

- [ ] 전시 화면 첫 피드 카드 상단이 `y ≈ 312` (현재 730)
- [ ] 홈 첫 전시 카드가 주목 상위 구간 `0–422` 안에서 시작
- [ ] 홈에서 진행 중·예정·지난이 **라벨을 안 보고도** 형태로 구별됨
- [ ] 지난 전시가 기본 접힘
- [ ] 로미 한 줄·근거가 16px 이상, 행간 1.6 이상
- [ ] 12px(`text-xs`)에 문장이 없음 — 배지·라벨·코드만
- [ ] 유틸 행 3칸 모두 엄지로 누를 수 있음 (44px)
- [ ] 한 화면에 primary가 하나
- [ ] 컴패니언 필이 마지막 카드를 가리지 않음

## 함정 (미리 적어둔다)

| 함정 | 대응 |
|---|---|
| `끌림`·`이미 봄`을 쓰면 `brand-voice.test.ts`가 깨진다 | 현재 어휘는 `꼭 갈래`·`끌려`·`패스` / `좋았어`·`그냥그랬어`·`아니었어` |
| 새 문구를 `ko`에만 넣으면 키 일치 테스트가 깨진다 | `en`도 같은 키로 |
| 원시 `--text-*`를 건드리면 버튼·칩 높이가 바뀐다 | 유틸리티만 추가. 원시 스케일은 SEED 공유값 |
| 글자를 키우면 `line-clamp`이 더 자른다 | 클램프 줄 수를 같이 조정 |
| `listBoothsByExhibitionId`가 `enrichment`를 안 주면 `로미가 아는 곳`이 전부 0 | Task 8 Step 8에서 운영 dry-run으로 확인. 0이면 그 신호만 빼고 별도 태스크 |
| 홈에서 부스를 두 번 읽게 된다 | `hasInterest` 분기와 신호 계산을 한 루프로 합친다 |
| 서버 컴포넌트에 `useState` 못 쓴다 | 유틸 행 + 검색을 `ExhibitionUtilityBar` 클라 컴포넌트로 묶음 |
| 종료 전시가 피드·회고 화면으로 간다 | 이번엔 `primaryAction`으로 부분 완화만. 전용 화면은 별도 플랜 |
