# iOS 재구축 토대 API와 DB (2026-11-17)

화면 설계서(`Roam-design/docs/product/2026-11-17_화면-설계서/`)의 개발 순서 1번이다. iOS를 다시 만들기 전에 서버가 받아야 할 것을 먼저 더했다. 현장에 있는 iOS 앱이 옛 칸을 계속 쓰므로 전부 **더하기만** 했다.

## 결정 (Ted)

- 다녀왔어요는 평가와 따로 저장한다(11-17, `Roam-design/docs/decisions/2026-11-17_다녀왔어요-평가와-따로-저장.md`).
- 가기 전 판단은 하트 하나(11-07). 하트는 `booth_note`에 둔다(설계서 README 헤더 기본값 1).
- 브랜드 하트는 부스 하트와 따로 저장한다. 부스 없는 참가에도 남는다(11-17).
- 브랜드 알림은 로그인한 분에게만. 로그인 안 한 기기 토큰은 있어도 되지만 브랜드 알림 대상은 `user_id`가 있는 토큰뿐(11-17).
- 로그아웃해도 기기 기록은 남긴다. 계정 삭제는 서버 데이터를 지운다(11-17). 계정은 바로 지운다(11-16).
- 회고 글은 기기에만 둔다. 서버 칸 없음. 매거진은 나중(11-17).

## 바꾼 것

| 영역 | 무엇 | 왜 이 모양인가 |
|---|---|---|
| 노트 | `visited`, `heart` 입력. `visited_at`을 평가와 따로 쓰고 지움. `hearted_at`, `verdict_at` 칸(0064) | 규칙 한 곳(`src/lib/notes/apply.ts`)을 supabase와 mock이 같이 쓴다. 옛 interest는 계속 맞춰 써서 옛 앱과 웹이 그대로 읽는다 |
| 하트 트리거 | 0064의 `booth_note_sync_heart` | 옛 iOS는 서버를 거치지 않고 Supabase에 interest만 쓴다. 그때도 `hearted_at`이 따라가야 한다 |
| 신호 | `heart_added`(가중치 1.0), `heart_removed`, `visit_marked`, `visit_unmarked`(가중치 0) | 다녀왔다고 좋아하는 게 아니고, 하트를 뺐다고 싫어하는 게 아니다(브랜드 규칙 §4). 원장에는 남긴다 |
| 부스 응답 | `exhibitorId`, `participantId` | 브랜드 하트, 알림, 다음 박람회 잇기의 열쇠. 저장소가 아니라 앱이 받는 두 라우트에서만 붙인다(피드, 인입이 같은 읽기를 쓰므로) |
| 이벤트 | `analytics_event` 넓히기(0066), 묶음 받기 | 외부 분석 도구 대신 자체 표. `booth_note`와 한 쿼리로 묶이고 수탁사가 늘지 않는다(설계서 E 2-2). 단점: 화면과 퍼널을 직접 만들어야 한다 |
| 개인정보 | 속성에서 좌표, 메모, 회고, 묻는 말, 닉네임, 검색어 키와 80자 넘는 글을 지움 | 설계서 E 2-1. 이름 목록은 iOS enum이 단일 소스라 서버는 이름을 막지 않고 모양과 개인정보만 지킨다 |
| 푸시 | `push_device`(0067), `POST/DELETE /api/push/subscribe` | 보내기는 아직 없다. 웹 옛 모양은 저장하지 않는다(웹 푸시는 꺼져 있다) |
| 브랜드 하트 | `brand_heart`(0068), `/api/me/brand-hearts` | 브랜드(exhibitor)에 건다. 브랜드를 합치면 하트도 옮긴다. 계정 병합 함수도 옮긴다(0069) |
| 계정 삭제 | `DELETE /api/me` | 데이터와 auth 사용자를 지운다. 이벤트와 오류 로그는 계정 연결만 끊는다 |
| 노트 목록 | `GET /api/me/notes?expand=booth` | 마이페이지, 내보내기. 기본 모양은 그대로 |
| 도면 | `version`, `scale`, ETag, `GET /api/floorplans` | 앱이 기기 사본을 304로 확인한다. version은 내용 해시라 손으로 올릴 번호가 없다 |

## 버린 안

- **하트를 `interest`에 새 값 `heart`로 더하기.** 옛 iOS가 모르는 값을 읽으면 디코딩이 깨질 수 있다. 시각도 따로 없다.
- **하트를 `bookmark`(target booth)로.** 로그인 필수 API이고 기기 먼저 길이 없다.
- **이벤트에 외부 SDK(PostHog 등).** 위 표.
- **`analytics_event.session_id`를 앱 세션 id로 재사용.** `visitor_session` FK가 박람회를 요구한다. 앱 세션은 `app_session_id`로 따로 뒀다.

## 남은 것

- **Apple 토큰 취소**(App Store 5.1.1(v)): 서버에 Apple 클라이언트 시크릿이 없다. `src/lib/auth/delete-auth-users.ts` TODO.
- **웹 평가 해제의 뜻이 바뀜**: 웹에서 평가를 지우면 이제 방문이 남아 "다녀왔는데 평가 없음" 되묻기(`pending-retro`)에 들어간다. 결정대로지만 웹 화면에는 다녀왔어요 끄기 버튼이 없다.
- **`anon_link` 표**(설계서 E 7절): 이벤트 행마다 `anon_id`와 `user_id`를 같이 적어서 지금은 따로 두지 않았다.
- 배포 순서: **0064를 적용한 뒤 배포**해야 한다. 이 브랜치의 노트 쓰기가 `hearted_at`, `verdict_at`을 쓴다.
