# 버튼 클릭 집계 (admin "버튼 인기도")

**날짜**: 2026-08-13
**관련 파일**: exhibition-map.tsx, interest-feed.tsx, companion-bar.tsx, finish-visit.tsx, admin/analytics

## What — 무엇이 달라졌나
admin 분석 화면에 "버튼 인기도" 패널이 추가됐다. 지도 확대/축소/전체보기/회전,
피드 소진 화면의 마치기·지도로가기·새로 고르기, 컴패니언 바 열기·FAQ 3개,
관람 마치기 시작 버튼 — 전체 방문객이 각 버튼을 얼마나 눌렀는지 집계해 막대그래프로
보여준다. 개인별 기록이 아니라 전체 합계다.

## Why — 왜 필요했나
운영진이 "사람들이 실제로 어떤 버튼을 많이 쓰는지" 볼 방법이 없었다. 온보딩에서
고른 가치 집계는 이미 있었지만, 지도 조작이나 컴패니언 바처럼 화면 안 상호작용은
전혀 안 보였다.

## 판단 근거
새 이벤트 종류를 버튼마다 늘리지 않고 기존 클릭 로그 체계에 종류 하나("버튼
클릭")만 더해 재사용했다 — 운영 데이터 스키마를 불필요하게 불리지 않으면서
필요한 통계는 그대로 얻는다.
