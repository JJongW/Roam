# SIF 2026 도면 좌표 재생성

날짜: 2026-07-28
대상 전시: `sif-2026` (2026 서울일러스트레이션페어, 코엑스 C홀)

## 문제

`src/lib/floorplan-sif.json`의 부스 지오메트리가 공식 도면과 맞지 않는다.

- 부스 913개가 단 2가지 크기(`42×40` 812개, `52×46` 101개)로만 되어 있다. 실제 도면은
  부스 크기가 제각각이다.
- 위치가 어긋난다. 공식 좌표 대비 `|Δx|+|Δy|` 중앙값 **343px**, 최대 824px(`V15`).
- 위치·크기가 모두 정확히 일치하는 부스가 **0개**다.
- 도면의 빈 공간(부스가 없는 자리)이 균일 격자에 뭉개져 사라졌다.

결과적으로 방문객이 지도에서 읽는 위치가 현장과 다르다.

## 데이터 소스

ocreo(공식 플랫폼) 프론트엔드 번들 `https://www.ocreo.kr/static/js/main.ed95579d.js`에
도면이 **인라인 React SVG**로 들어 있다. 번들에는 서로 다른 페어의 지도 컴포넌트가 4개
있으며(파일 오프셋 4645 / 1607932 / 4540472 / 7453442), 이 중 **오프셋 4540472의
컴포넌트가 sif21**이다. 근거:

- `g[id]` 부스 코드 914개 중 913개가 현재 `floorplan-sif.json`의 코드와 정확히 일치
  (나머지 3개 컴포넌트는 100~470개가 어긋난다).
- 부스 채우기 색이 우리 `cat` 필드와 1:1로 대응한다:
  `#CFEEFF`→국내작가 718, `#FFDFAB`→국내기업 124, `#DCDDFF`→해외작가 64,
  `#C6ECDF`→해외기업 4. (예외 3건은 아래 "불일치 처리" 참조.)
- 렌더 스타일(`rx:3` 라운드 + 흰 스트로크 + 파스텔 팔레트)이 공식 도면 이미지
  `public/fair-map.jpg`와 일치한다.

각 부스는 `<g id="{부스코드}"><rect x y width height rx=3 fill=.../>` 형태라 좌표를
정규식으로 그대로 뽑을 수 있다.

**`fair-map.jpg`는 트레이싱 대상이 아니다.** 결과를 눈으로 대조하는 검증용 참조 이미지로만
쓴다. 좌표는 전부 번들에서 온다.

추출 스크립트는 **레포에 커밋하지 않는다.** 번들 파일명에 콘텐츠 해시가 박혀 있어
(`main.ed95579d.js`) ocreo가 배포하면 즉시 못 쓰는 스크립트가 된다. 스크래치패드에서
일회성으로 돌리고 결과 JSON만 커밋한다. 재추출이 필요하면 이 문서의 "데이터 소스" 절을
보고 다시 만든다.

## 변경 사항

### 1. `src/lib/floorplan-sif.json` — 전면 재생성

| 항목 | 현재 | 변경 후 |
|---|---|---|
| 캔버스 | `2584 × 1506` | `3028 × 1637` |
| 부스 수 | 913 | 914 (`O08` 추가) |
| 부스 크기 종류 | 2 | 19 |
| 좌표 정확도 | 0/913 일치 | 914/914 공식 도면과 일치 |

스키마는 그대로 둔다: `{ width, height, booths: [{ code, x, y, w, h, zone, name, cat }] }`.

- `x/y/w/h` — ocreo SVG 값을 그대로. 좌상단 기준(현행 규약 유지).
- `code` — 변경 없음.
- `name` — 기존 값을 `code`로 조인해 보존. 신규 `O08`은 ocreo 참가자 API에서 상호를
  조회해 채우고, 조회되지 않으면 코드만 남긴다(`name`은 빈 문자열이 아니라 `"O08"`).
- `cat` — ocreo 채우기 색에서 도출. 기존 값과 3건 불일치 시 ocreo를 따른다(아래 참조).
- `zone` — 전부 `"general"` 유지 (SIF 도면에 존 구분이 없다).

부스가 없는 자리는 **아무것도 넣지 않는다.** 좌표가 정확해지면 빈 공간이 자연히 빈 공간으로
남는다. "빈칸"을 표현하는 별도 엔티티를 만들지 않는다.

### 2. `src/lib/floorplans.ts` — `buildSif()` 좌표 규약 수정

`FloorplanBooth.x/y`는 **중심 기준**이다 (`exhibition-map.tsx`가
`<rect x={-g.w/2} y={-g.h/2}>`를 `translate(g.x, g.y)` 안에 그린다). 그런데
`buildSif()`는 좌상단 기준인 JSON 값을 변환 없이 그대로 넘기고 있다.

지금까지는 전 부스가 42×40 균일이라 화면 전체가 `(21, 20)`만큼 평행이동한 것과 같아 눈에
띄지 않았다. 크기가 40×40부터 50×360까지 제각각이 되면 **부스마다 다른 크기로 어긋나므로**
반드시 고쳐야 한다.

```
booths: sif.booths.map((b) => ({
  code: b.code,
  x: b.x + b.w / 2,   // 좌상단 → 중심
  y: b.y + b.h / 2,
  w: b.w,
  h: b.h,
  color: ZONE.general,
}))
```

같은 함수의 `bbox` 계산은 이미 `b.x + b.w/2`로 중심을 구하고 있으므로, 변환된 booths를
그대로 넘기도록 정리한다(중복 계산 제거).

`entrance`/`exit`는 현행 유지(`width/2`, `height-60`) — 이번 범위 밖.

### 3. 운영 DB 마이그레이션 — `supabase/migrations/0026_sif_booth_fixes.sql`

**지오메트리는 마이그레이션이 필요 없다.** `exhibition-map.tsx`의 `geomOf()`가 부스 `code`로
`FLOORPLANS`를 먼저 조회하고, 찾으면 DB의 `booth.x/y`를 쓰지 않는다. 좌표 수정은 배포만으로
운영에 반영된다.

DB 행이 필요한 건 세 가지다:

1. **`exhibition.map_width` / `map_height` UPDATE — 필수.** `map-view.tsx:159`가
   floorplan이 아니라 `exhibition.mapWidth/mapHeight`를 `ExhibitionMap`의 캔버스 크기로
   넘긴다. 운영 DB 값은 옛 `2584 × 1506`이라, 이걸 안 고치면 부스는 x=2918까지 뻗는데
   뷰포트는 2584에서 끊겨 **도면 오른쪽(S·T·U·V 블록)이 잘린다.** mock 모드는
   `seed-sif.ts`가 `sifFloor.width/height`를 읽으므로 자동 반영되지만, 운영은 안 된다.
   `3028 × 1637`로 UPDATE.
2. **`O08` 부스 INSERT** — 없으면 지도에 그려지지 않는다. `exhibition-map.tsx`는 DB에서 온
   부스 목록을 순회하며 floorplan을 조회하는 구조라, floorplan에만 있고 DB에 없는 코드는
   렌더링 대상에서 빠진다. `sif-2026` 전시 · `hall_sif` 홀 · `#C6ECDF`가 가리키는
   해외기업 카테고리로 넣는다.
3. **카테고리 교정 3건** — ocreo가 해외작가(`#DCDDFF`)로 칠했으나 우리 데이터엔
   국내작가로 들어간 부스. `booth.category_id`를 해외작가로 UPDATE.

멱등하게 작성한다(`INSERT ... ON CONFLICT DO UPDATE`, `UPDATE ... WHERE`). `supabase/`는
gitignore이므로 파일은 로컬에만 생기고, **적용은 사용자가 직접 한다.**

### 4. 범위 밖 (이번에 안 함)

도면에는 CAFE 블록 2개(`CAFE_A`, `CAFE_B`), 출입구 GATE, 화장실, 벽선, 상단 입구 아이콘이
있고 번들에서 좌표를 뽑을 수 있지만 **이번엔 넣지 않는다.** SIF floorplan의 `halls`/`decor`는
빈 배열로 둔다. 부스 위치 정확도가 이번 작업의 목표이고, decor는 별건이다.

## 검증

1. **시각 대조** — 새 `floorplan-sif.json`으로 정적 SVG를 렌더해 `public/fair-map.jpg`와
   나란히 놓고 확인한다. 블록 배치·큰 부스·빈 공간이 일치해야 한다.
2. **불변식 어서션** (일회성 스크립트, 커밋 안 함)
   - 부스 간 사각형 겹침 0건
   - 모든 부스가 캔버스 `3028 × 1637` 안에 있음
   - 부스 코드 914개 전부 유일
   - `name`이 비어 있는 부스 0건
3. **기존 검증 파이프라인**
   ```
   npx tsc --noEmit
   npx vitest run
   npx eslint src/lib/floorplans.ts src/lib/mock/seed-sif.ts
   ```
4. **mock 모드 실행 확인** — 지도 화면에서 부스 크기 차이와 빈 공간이 보이는지, 도면
   오른쪽 끝(V01~V16 세로 열)까지 잘리지 않고 보이는지, 부스를 눌렀을 때 위치가 맞는지
   확인한다.
   ```
   NEXT_PUBLIC_SUPABASE_URL= NEXT_PUBLIC_SUPABASE_ANON_KEY= SUPABASE_SERVICE_ROLE_KEY= npx next dev
   ```

## 리스크

- **ocreo가 페어 전에 도면을 갱신하면** 좌표가 다시 낡는다. 재추출 절차는 이 문서에 있다.
  페어 개막(2026-07-30) 직전 한 번 대조를 권한다.
- **번들 파싱은 정규식 기반**이라 ocreo의 빌드 출력 형태가 바뀌면 깨진다. 일회성 추출이므로
  이번 실행만 성공하면 되고, 결과는 위 불변식 어서션으로 검증한다.
