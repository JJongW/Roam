# admin 계정 상세 페이지 확장

**날짜**: 2026-08-12
**관련 파일**: page.tsx(계정 상세), route.ts(관리자 사용자 API), timeline.ts

## What — 무엇이 달라졌나

관리자가 계정 상세 페이지에서 그 사용자의 취향이 어느 쪽으로 치우쳤는지 레이더 그래프로 바로 볼 수 있게 됐다. 반응 타임라인도 이제 날짜별로 구분선이 붙어서, 어느 날 무슨 반응을 했는지 한눈에 들어온다.

## Why — 왜 필요했나

지금까지 관리자는 사용자의 반응 기록을 그냥 최신순으로 죽 나열된 목록으로만 봤고, 그 사용자가 어떤 취향에 가까운지는 전혀 알 방법이 없었다. 방문객 자신은 이미 자기 취향 레이더를 볼 수 있는데 관리자만 못 보고 있었다.

## 판단 근거

새로운 시각화를 따로 만들지 않고 방문객이 보는 것과 완전히 같은 취향 레이더 컴포넌트를 재사용했다 — 관리자가 보는 숫자와 사용자 자신이 보는 숫자가 갈리면 안 되기 때문이다. 날짜 구분은 캘린더나 히트맵 같은 별도 뷰 대신 기존 타임라인 목록 안에 헤더만 끼워 넣는 가장 가벼운 형태로 했다 — 이미 있는 목록의 가독성만 높이면 되는 문제였지 새 화면이 필요한 문제가 아니었다.
