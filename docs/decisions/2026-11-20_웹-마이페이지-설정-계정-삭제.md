# 웹 마이페이지, 설정, 계정 삭제

_2026-11-20. 브랜치 `feat/web-mypage`. #198(로미 시트, 회고, 알림함, 길 안내) 위에 쌓았다. #194 → #198 → 이것 순서로 머지한다._

## 왜

웹에는 남긴 하트와 다녀온 기록을 한곳에서 보는 자리가 없었다. #198에서 회고를 남길 수 있게 됐지만 다시 읽는 자리(40-C)가
없었고, 하트 남긴 브랜드(14-10)와 계정 삭제(15-11)로 가는 길도 없었다. Figma UI v1 섹션 14, 15대로 만든다.

## 결정 근거

- 화면은 Figma UI 14(14-01~14-10), 15(15-01, 15-02, 15-03, 15-09, 15-11~15-13), 12-05(40-C)만 옮겼다. Figma에 없는 화면은 만들지 않았다.
- 마이페이지는 로그인 없이 연다(14-01, 로그인은 입장 조건이 아니다, 브랜드 규칙 §4). 로그인 전 하트는 이 브라우저에만 있다고 사실대로 말한다.
- 계정 삭제는 서버 `DELETE /api/me`가 이미 있어(계정의 하트, 기록, 평가, 메모, 브랜드 하트, 닉네임, 기기 토큰을 바로 지움) 화면만 더했다.
  지운 뒤 이 브라우저의 기록도 로그아웃처럼 비운다.
- 하트 빼기는 확인 없이 바로, 스낵바로 되돌린다(11-12 HX-A, 14-09). 체크와 메모는 남는다.

## 웹에서 바꾸거나 뺀 것

- "이 휴대폰" → "이 브라우저"(14-01, 14-02, 15-09).
- 15-01에서 뺀 줄: 알림 묶음(13-09, 아래), 지도 보기와 홀 이름 보기와 위치 권한(iOS 기기 설정), 기록 내보내기(웹에 없다), 버전.
  15-11의 "지우기 전에 / 기록 내보내기"도 같은 이유로 뺐다.
- 13-09 알림 설정은 만들지 않았다. 서버에는 `brand_appear` 하나(`/api/me/notification-prefs`)가 있지만 웹은 푸시를 보내지 않고,
  끈 분의 알림 줄도 알림함에는 그대로 남는다(`muted`). 웹에서 바꿔도 웹만 쓰는 분에게 달라지는 것이 없어 켜고 끄는 줄은 거짓 약속이 된다.
- 14-10의 "서울디자인페스티벌 2025에 나왔어요"(지난 참가)는 API가 주지 않아 비운다.
- 12-05의 "다음 박람회에도 나와요"(좋았어요 남긴 브랜드의 다음 출전)는 그 API가 없어 아직 없다(설계서 12-05 표). 쓰신 말만 보인다.
- 맨 위 카드의 넘김 점(여러 박람회)은 아직 없다. 다음 박람회 한 장이다.
- 14-06의 "지도 보기"는 지금 열린 박람회가 있을 때만 둔다. 다가오는 박람회는 지도가 아직 없을 수 있다(11-20 "지도 없는 박람회는 흐린 진행 예정").
- 브랜드 검토(11-20)로 고친 말: "이 지도에 켜져요" → "박람회 지도에 켜져요"(가리킬 지도가 없는 화면이 있다).
  14-05는 지도를 그릴 수 있을 때만 "하트 남긴 곳이 지도에 켜져 있어요"를 붙인다.
- 홈 머리에 없던 v1 동행 바(`CompanionBar`)는 `/me`, `/me/*`, `/inbox`에서 숨긴다. 아래 붙은 버튼과 시트를 덮었다.
- 시트(`BottomSheet`)를 넓은 화면에서 가운데로 둔다(1280에서 왼쪽에 붙어 있었다, #198 것).

## 버린 방법

- **iOS처럼 하단 탭 바를 웹에 그리기**: 웹 홈과 지도에 탭 바가 없어 마이페이지에만 탭이 생긴다. 홈 머리 아이콘 하나로 들어온다.
- **설정을 로그인한 분만 열기**: Figma 14-01에도 설정 톱니가 있다. 로그인 전에는 프로필과 계정 묶음 없이 연다.

## 남은 것

- 개인정보 처리방침(`/privacy`)은 아직 "메일로 요청하면 30일 안에 지운다"고 적혀 있다. 이 화면은 바로 지운다. 문서 고침은 따로 정한다.
- 로그아웃하면 웹은 이 브라우저의 기록을 비운다(stores/auth.ts). 11-17 결정 "로그아웃해도 기기 기록 유지"(iOS)와 다르다. 이번에는 바꾸지 않았다.
- 서버 닉네임은 20자, Figma는 12자. 화면은 12자로 막는다.
