# 연락 현황판: 안 보냄과 연락 수단 없음 나누기

_2026-11-28 · Ted 요청 ("이거 admin에 아직 안보냄과 보낼 연락수단이 없는 거랑은 구분 해야할 거같은데")_

## 무엇을 했나

- `/admin/brands/contacts`에서 저장 상태가 "안 보냄"인데 보낼 연락 수단이 하나도 없는 줄을 **"연락 수단 없음"**으로 따로 보인다. 상태 칩, 위쪽 상태 칸(개수와 거르기), 쌓인 막대, 상태순 정렬이 모두 이 기준을 쓴다.
- 연락 수단 칸(옛 "인스타" 칸)이 무엇으로 보낼지 보여 준다. 맨 앞 수단을 크게, 나머지는 작은 표(메일, X, 기타)로 옆에 둔다.
- "계정 있음/없음" 거르기를 "연락 수단 있음/없음"으로 바꾸고 같은 기준(인스타, 메일, X, 기타)을 쓴다. 위쪽 요약 줄의 "계정 모름" 숫자는 새 상태 칸과 겹쳐서 뺐다.

## 무엇을 연락 수단으로 세나

| 수단 | 오는 곳(앞일수록 먼저) |
|---|---|
| 인스타 | 연락 기록의 계정 → 브랜드 프로필 links 칸 instagram → 브랜드 공식 링크(exhibitor.instagram_url) → 대표 부스 링크(기존 순서 그대로) |
| 메일 | 연락 기록의 계정이 메일 모양 → 브랜드 프로필 links 칸의 `mailto:` 링크 |
| X | 연락 기록 채널이 X인 계정 → 브랜드 프로필 links 칸 x |
| 기타 | 연락 기록 채널이 기타인 계정(사람이 적은 값) |

사이트와 판매 페이지 링크는 보내는 곳이 아니라 세지 않는다. 사이트에서 메일을 찾으면 자세히에서 메일을 적으면 된다.

## 왜 이렇게 했나

- **저장값은 그대로**: 연락 상태 아홉 개(BrandContactStatus)와 DB는 손대지 않았다. "연락 수단 없음"은 `boardStatus()`가 줄마다 계산한다. 그래서 자세히에서 계정이나 메일을 확정하면 그 자리에서, 인스타 csv 가져오기를 적용하면 새로고침 뒤 바로 "안 보냄"으로 돌아간다. 따로 옮기는 동작이 없다.
- 상태 숫자 키(1~9)는 저장 상태에만 붙는다. 연락 수단 없음 칸에는 숫자가 없다.
- 칩 모양은 안 보냄보다 흐린 점선 테두리로 했다. "보낼 수 있는데 아직"과 "보낼 곳부터 찾아야 함"이 한눈에 갈리게 하려는 것이다. 기존 토큰(muted-foreground)만 쓴다.

## 버린 방법

- **새 저장 상태(`no-channel`)를 DB에 더하기**: 연락처가 생길 때마다 상태를 다시 바꿔야 하고, 빠뜨리면 계정이 있는데도 "연락 수단 없음"에 남는다. 계산이 더 안전하다.
- **사이트 링크도 연락 수단으로 세기**: 사이트만 있는 곳이 "안 보냄"에 섞여 지금과 같은 문제가 남는다.

## 남은 일(만들지 않고 보고만)

- 웹 검색으로 찾은 메일을 여러 곳 한꺼번에 넣는 가져오기는 없다. 지금은 자세히에서 한 곳씩 적는다.
- 연락하지 않을 곳(대상 제외)을 따로 두는 상태는 없다. 지금은 연락 금지 스위치가 그 역할을 일부 한다.

## 브랜드 목록과 상세에도 같은 구분(같은 날 이어서)

Ted가 다른 어드민 화면은 여전히 다 "안 보냄"이라 구분이 안 된다고 했다. 현황판에만 넣은 것을 브랜드 화면에도 넣었다.

- `/admin/brands`(브랜드 목록)의 최근 출전 상태 칩, `/admin/brands/[id]`(브랜드 상세) 연락 탭의 출전별 칩이 "연락 수단 없음"을 보인다.
- 기준을 새로 만들지 않았다. 현황판이 줄을 만들던 부분을 `rowsFromStates()`(`src/lib/brands/board-load.ts`)로 꺼내 세 화면이 같이 쓴다. 연락 수단 종류와 출처 순서가 화면마다 갈릴 수 없다. 칩은 같은 `StatusChip`, 계산은 같은 `boardStatus()`다.
- 브랜드 목록은 예전엔 상태만 읽었다(`store.statuses`). 연락 기록의 계정도 연락 수단이라 이제 `store.read`로 연락처까지 읽는다.
- 상세에서 연락 기록을 고치면 현황판과 같은 `applyContactResult()`로 줄을 고쳐, 계정을 적는 즉시 "안 보냄"으로 돌아간다.

일부러 안 고친 곳:

- 연락 기록 시트(`brand-contact-sheet.tsx`)의 상태 바꾸기 버튼: 저장값을 고르는 자리라 저장 상태 아홉 개 그대로 둔다.
- 관리자 홈 "브랜드 연락 할 일": 안 보냄을 세지 않고 할 일 표시만 센다.
- 인스타 게시 허락 검사(`permission-gate.ts`): 저장값으로 막는 검사라 화면 상태와 무관하다.
- `summarizeContacts()`(`contact.ts`): 화면에서 쓰는 곳이 없다.
