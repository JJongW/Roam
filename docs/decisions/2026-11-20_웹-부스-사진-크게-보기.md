# 웹 부스 사진 크게 보기와 지도에서 보기(UI 4-03, 4-07)

_2026-11-20. 브랜치 `feat/web-booth-photo-viewer`. main(#201 머지 뒤) 위에서 팠다._

## 왜

인계 현황판(Roam-design `docs/product/handoff.md`) UI 4 웹 칸이 "4-01, 4-02, 4-06 있음. 4-03 확인 안 됨, 4-04, 4-05, 4-07 대조"였다.
Figma UI 4와 대조해 빠진 것을 채운다.

## 대조 결과

| 화면 | 웹 | 이번에 |
|---|---|---|
| 4-03 사진 크게 보기 | 없음. 상세 사진을 눌러도 아무 일이 없었다 | 만듦 |
| 4-04 사진이 없을 때 | 있음. 사진이 없으면 사진 줄을 통째로 뺀다 | 그대로 |
| 4-05 소개가 없을 때 | 있음. 소개 상자와 인스타그램 줄이 빠지고, 파는 것이 있으면 "이름과 위치만" 줄도 없다 | 그대로 |
| 4-07 지도에서 보기 | 부분. 지도와 카드는 열렸지만 상세 위에 지도를 쌓았다 | 고침 |

## 결정 근거

- 4-03(11-13 "세로 3:4 옆으로 넘김, 바는 알약"): 화면 전체 어두운 바탕(bg/neutral-solid), 왼쪽 위 X(icon/x 24, 누르는 영역 44),
  가운데 세로 3:4 사진 칸, 아래 알약 "2 / 5". 옆으로 넘기기는 CSS 스크롤 스냅이라 의존성을 더하지 않았다.
  가로 사진은 잘리지 않게 칸 안에 담는다(설계서 4-03 "가로 사진은 위아래가 많이 남아요").
- 4-07(11-13 "화면을 쌓지 않고 상세를 닫아"): "지도에서 보기"를 `router.replace`로 바꿨다. 지도 → 상세 → 지도에서 보기 뒤
  뒤로 가기 한 번이면 상세 전에 있던 화면이다. 새 탭으로 여는 누름(Cmd, Ctrl, 가운데 단추)은 그대로 둔다.
- 기록: 열 때 `screen_view`(UI 4-03, 시작 장, 전체 장), 처음 보는 장으로 넘길 때마다 `booth_photo_swipe`(iOS와 같은 이름).

## 만들지 않은 것

- 두 손가락 확대, 아래로 밀어 닫기: Figma에 없다(설계서 4-03 "미정 47-3").
- 상세 아래 바의 "길 안내" 버튼(4-02, 4-04, 4-05 Figma에 있음): 웹 길 안내(UI 9)는 지도 화면 안에서만 시작한다. 상세에서
  시작하려면 지도에 길 안내를 여는 주소 인자를 더해야 하고, 지도 화면 파일은 같은 시간에 다른 작업이 고치고 있어 이번에 넣지 않았다.
- 분류 칩 여러 개와 "체험 있음"(4-02): 부스 데이터의 분류가 하나뿐이고 "체험 있음" 원천은 정해지지 않았다(설계서 D12).
- 위치 줄의 "출입구에서 걸어서 2분쯤": 배치도에 축척이 없어 말하지 않는다(UI 9와 같은 이유).
