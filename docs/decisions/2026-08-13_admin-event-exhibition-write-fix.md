# admin 이벤트·전시 저장 실패 수정

**날짜**: 2026-08-13
**관련 파일**: supabase/repository.ts

## What — 무엇이 달라졌나
관리자 콘솔에서 새 이벤트를 등록하거나 전시 정보를 수정할 때 "네트워크 오류"만 뜨고 저장이 안 되던 문제가 고쳐졌다. 이제 정상적으로 저장된다.

## Why — 왜 필요했나
운영자가 부스 이벤트나 전시 정보를 입력해도 저장 버튼을 누르면 계속 실패했다 — 데이터를 만들 수 없어 실질적으로 이벤트·전시 관리 기능을 쓸 수 없는 상태였다.

## 판단 근거
같은 문제를 부스 관리에서 이미 한 번 겪고 고친 적이 있었다 — 이번에도 같은 원인이라 같은 방식으로 맞췄다. 운영자 전용 기능은 운영자 권한으로 동작해야 실수로 막히지 않는다.
