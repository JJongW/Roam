# 지도 확인 알림을 화면 위 토스트로

_2026-11-27. Ted가 서울디자인페스티벌 현장에서 iOS를 쓰다가 정했어요. 헤더가 웹과 iOS에 같은 범위로 맡겼어요._

## 결정 (Ted)

> "이거 다녀왔어요 체크 알림뜨는게 토스트형태로 상단에 뜨게해야지 다음 부스 다녀왔어요를 지금 바로 누를 수가 없잖아"

지도 화면 아래쪽은 다음 부스를 고르고 누르는 자리예요. 부스 카드에서 생긴 확인 알림이 그 자리를 덮거나 카드를 밀어내면, 현장에서 부스를 하나씩 체크하며 걷는 흐름이 끊겨요.

## 바꾼 것

1. **옮긴 알림**(지도에서 부스 카드가 떠 있을 때)
   - 6-03 다녀왔어요를 켠 뒤: "‘이름’, 다녀온 곳으로 기억해 둘게요 / 어떠셨는지는 나중에 남기셔도 돼요." + 되돌리기. 예전에는 카드를 내리고 그 자리에 로미 줄(`RomiLineCard`, 6초)을 띄웠어요. 그동안 다른 부스를 눌러도 카드가 뜨지 않았어요.
   - 6-06 다녀왔어요를 끈 뒤의 되돌리기
   - 5-08 하트를 뺀 뒤의 되돌리기
2. **자리**: 찾기 띠(뒤로 가기, 찾기 줄, 편의시설 칩, 홀 버튼 줄) 바로 아래 8(`gap-v2-x2`). 띠와 같은 위 겹(z-30, `pt-safe`) 안에 두어서 띠 높이가 바뀌면(홀 목록 펼침, 칩 없음) 저절로 따라가요. 지도 맞추기 여백(`insets`)은 띠(`topRef`)만 재므로 토스트가 떠도 지도 크기와 카메라는 그대로예요.
3. **모양**: `components/v2/snackbar.tsx` 그대로예요(높이 48, 그림자 s3, 동작 칸 44, 동작 글자 `fg.brand-inverted`, 4초). 토큰만 써요. 6-03은 두 줄이라 `whitespace-pre-line`으로 줄을 나눠요.
4. **카드는 그대로 둬요**: 다녀왔어요를 켜도 카드를 내리지 않아요. 알약이 켜진 채 보이고, 지도에서 다음 부스를 누르면 카드가 바로 바뀌어요. 토스트는 다음 카드로 넘어가도 남아 있어요(지도 화면이 들고 있어서).
5. **한 번에 하나(섹션 33)**: 새 알림은 앞 알림을 바꿔요. 토스트가 뜨면 지도 아래 스낵바(오늘 다녀온 곳 시트에서 온 것)를 내리고, 그 반대도 같아요. 카드의 로그인 제안이 뜨면 토스트를 내려요.
6. 쓰이지 않게 된 `map-v2/romi-line-card.tsx`를 지웠어요(호출부가 이 화면 하나였어요).

- 문구는 바꾸지 않았어요.

## 11-25 규칙과의 관계

## 고르지 않은 안

- 토스트 자리를 띠 높이를 재서 `top` 값으로 계산: 띠와 같은 흐름에 두면 간격 하나로 맞고, 재는 코드는 띠가 바뀔 때 어긋나기 쉬워요.
- 다녀왔어요를 켜면 예전처럼 카드를 내림: 다음 부스로 가려면 지도를 한 번 더 눌러야 하는 건 같지만, 방금 켠 알약을 확인할 수 없어요. iOS도 고른 부스를 내리지 않아요.
- 6-03 둘째 줄("어떠셨는지는…")을 빼고 한 줄로: 문구는 그대로 두라는 범위라 두 줄로 뒀어요.

## iOS와 다른 점 (2026-11-27 dev 기준, iOS는 다른 에이전트가 고침)

- iOS dev에서 6-03은 아래 바의 로미 카드(`RomiCard`, 4초, `FairMapScreen.romiOverlay`)라 부스 카드보다 먼저 그려져 카드를 가려요. 6-06과 5-08은 `SnackbarCenter`가 부스 카드 윗선 위 8(`snackbarFloor(... "map.card", overhang: 18)`)에 띄워요. 이번 결정으로 iOS도 위로 옮겨요.
