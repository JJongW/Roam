# 로그인 세션 위조 방지

**날짜**: 2026-08-28
**관련 파일**: http.ts, env.ts, .env.example

## What — 무엇이 달라졌나
로그인 세션을 식별하는 값이 더 안전한 방식으로 바뀌었다. 사용자가 눈으로 느낄 변화는 없다 — 정상적으로 로그인·이용하는 데는 아무 영향이 없다.

## Why — 왜 필요했나
지금까지는 로그인한 사용자를 식별하는 값이 그대로 노출돼 있어서, 그 값을 알아낸 사람이 있다면 비밀번호나 별도 인증 없이도 다른 사람의 계정에 들어갈 수 있는 구조였다. 실제로 악용된 사례가 확인된 건 아니지만, iOS 앱을 새로 설계하며 인증 구조를 점검하던 중 이 위험을 발견해 먼저 손봤다.

## 판단 근거
계정을 노리는 부정 접근을 막는 건 방문객의 개인 기록(북마크·메모·취향 데이터 등)을 지키는 문제와 직결된다. 사용자가 직접 체감하지 못하는 영역이라도, 신뢰를 지키는 데 우선순위를 뒀다.
