# 좁은 화면 줄바꿈 개선

**날짜**: 2026-08-12
**관련 파일**: globals.css

## What — 무엇이 달라졌나

전시 홈, 온보딩, 회고 등 문장이 긴 화면에서 좁은 모바일 폭에 걸릴 때, "관심"처럼 짧은 단어 하나만 다음 줄에 외따로 남아 어색하게 끊기던 게 줄어든다.

## Why — 왜 필요했나

한글은 음절 중간에서 끊기지 않게 이미 처리돼 있었지만, 그것만으로는 "관심 가는 곳부터 같이 둘러보자" 같은 문장이 "관심"만 다음 줄로 넘어가 남는 걸 막지 못했다. 어절 단위로는 맞게 끊겨도 읽을 때 여전히 눈에 걸렸다.

## 판단 근거

특정 문장 하나하나를 손보는 대신 사이트 전체에 적용되는 CSS 속성 하나를 바꿨다 — 앞으로 새로 추가되는 문구에도 자동으로 적용되고, 지원 안 하는 브라우저에서는 그냥 기존 방식으로 자연스럽게 되돌아가 위험이 없다.
