# 웹 연결 문제와 스낵바 정리 (2026-11-25)

_브랜치 `fix/web-links-snackbar-1125`, origin/main 4a83038 기준 점검 결과를 고친다._

## 왜

헤더 점검에서 웹의 화면 연결이 설계서(Roam-design `docs/product/2026-11-17_화면-설계서/`)와 어긋난 곳이 나왔다.
막다른 화면, 같은 지도가 기록에 두 번 남는 것, 화면마다 다른 토스트 모양이다.

## 버린 안

- 웹 하단 탭 바를 새로 만들기: Figma 탭 바는 iOS 시스템 탭이고 웹용 부품과 토큰이 없다. 만들면 웹이 지어낸 부품이 된다. 웹에 탭 바를 둘지는 헤더가 정한다.
- 4-07에서 늘 `router.back()`: 다른 박람회나 마이페이지에서 온 상세면 지도가 아닌 화면으로 돌아간다.
- 로그아웃과 삭제 결과를 주소 쿼리로 넘기기: 새로 고침하면 다시 뜨고 주소가 지저분해진다.
