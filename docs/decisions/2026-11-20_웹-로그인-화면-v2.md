# 웹 로그인 화면 v2(UI 5-04~5-07)

_2026-11-20. 브랜치 `feat/web-login-v2`. main(#201 머지 뒤) 위에서 팠다._

## 왜

`/login`은 옛 화면(웹 v1 머리, Google 단추와 닉네임 칸을 나란히)이었다. Figma UI 5의 5-04(로그인), 5-05(로그인하고 돌아온 알림),
5-06(로그인 없이 계속), 5-07(로그인이 안 됐을 때)에 맞춘다.

## 결정 근거

- 웹의 실제 로그인 방식만 둔다. 운영은 Supabase Google 하나다(iOS는 Apple). 그래서 단추는 "Google로 로그인"이다.
  닉네임 로그인은 기존 계정 때문에 지우기를 보류 중이라(CLAUDE.md 로그인 게이트) 지우지 않고, 지금처럼 Supabase 키가 없는 로컬(mock)에서만 보인다.
- 5-04 문구: 제목 "로그인하시면 남긴 하트가 계정에도 남아요"(웹 다른 화면의 "로그인하시면"에 맞춤, Figma는 "로그인하면"),
  본문 "로그인하지 않아도 둘러보고 하트를 남길 수 있어요.". 로그인하면 이 브라우저의 하트와 다녀온 곳을 계정으로 올리는
  코드(`stores/auth.ts`)가 이미 있어 "계정에도 남아요"는 사실이다.
- 5-07: Google 창에서 사용자가 취소하면(`login_error=denied`) 실패가 아니라 5-04 그대로다(설계서 5-07 상태 규칙).
  그 밖의 실패는 "로그인을 마치지 못했어요 / 하트는 이 브라우저에 그대로 있어요. 잠시 뒤에 다시 해 보셔도 돼요." 와 "나중에 할게요".
  이유는 화면에 보이지 않고 콘솔과 서버 로그에만 남는다. 실패 때 `/auth/callback`이 `next`를 이어 줘 다시 하면 원래 가려던 곳으로 간다.
  `/login`에서는 AuthBootstrap의 실패 토스트를 띄우지 않는다(화면이 이미 5-07이다).
- 5-05: 로그인 시작 때 탭 단위 표시(sessionStorage `roam.login.started`)를 남기고, 돌아와 로그인이 확인되면
  "로그인했어요. 남긴 하트는 그대로 있어요."를 한 번 띄운다. 이때는 옛 "아까 남기신 반응도 반영했어요…" 알림을 띄우지 않는다.
- 5-06: "로그인 없이 둘러보기"는 앱 안에서 왔으면 뒤로, 바로 열었거나 Google에서 돌아왔으면 홈으로.
- 기록: `login_skip`, `login_complete`, `login_fail`(iOS AnalyticsTaxonomy와 같은 이름), 화면 id UI 5-04.

## Figma와 다르게 한 것

- 시트가 아니라 페이지다. 로그인이 필요한 주소에서 proxy가 `/login?next=`로 보내므로 주소가 있는 화면이 필요하다. 내용은 화면
  아래에 시트 모양으로 모았다(위는 빈 바탕).
- "Apple로 로그인" 대신 "Google로 로그인", "이 휴대폰" 대신 "이 브라우저".
- 맨 아래 개인정보처리방침과 이용약관 줄을 남겼다. Google OAuth 심사가 로그인 화면에서 방침에 닿기를 요구한다(`legal-links.tsx`).

## 건드리지 않은 것

- 5-03 로그인 제안 토스트의 위/아래 A/B 배정은 다른 작업이 맡는다.
- 옛 전역 로그인 시트(`LoginSheet`, `openLogin`)는 옛 화면(v1 부스 패널, 계정 단추)에서만 열려 그대로 뒀다.
