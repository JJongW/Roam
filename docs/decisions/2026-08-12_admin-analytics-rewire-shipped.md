# admin 분석 화면 재배선 + 여정 퍼널

**날짜**: 2026-08-12
**관련 파일**: admin/analytics/page.tsx, journey-funnel.ts, repository.ts(mock·supabase)

## What — 무엇이 달라졌나

관리자 분석 화면의 "전환율" 위젯이 죽은 옛 기능(동선·온보딩 설문) 데이터를 보여주던 걸, 실제 사용자 여정(로그인→가치 온보딩→반응→판정→회고)을 보여주는 "여정 퍼널"로 바꿨다. "인기 부스"도 가짜 기본값을 섞어 보여주던 걸 실제 조회수만으로 보여주게 했고, "방문 흐름"도 더는 안 쌓이는 데이터 대신 실제 조회 흐름의 근사치로 대체했다.

## Why — 왜 필요했나

지금까지 이 화면의 지표들은 이미 제거된 기능(동선 추천)이 쓰던 데이터를 그대로 읽고 있어서, 인기 부스는 항상 비슷한 값만 나오고 방문 흐름·전환율은 사실상 빈 화면이었다. 주최자가 실제로 사람들이 어떻게 관람하는지 알 방법이 없었다.

## 판단 근거

전환율 위젯을 고치는 과정에서, 정작 그 데이터의 출처인 "부스 조회" 기록 자체가 전시 정보 없이 저장되고 있다는 걸 발견했다 — 위젯만 고치면 여전히 빈 화면이 나올 뻔했다. 근본 원인(조회 기록에 전시가 안 붙던 것)부터 고쳐야 위젯 교체가 의미가 있다고 판단해 같이 손봤다. 여정 퍼널의 "가치 온보딩 완료" 단계도 처음엔 다른 화면(내 취향 수정)의 동작을 온보딩으로 착각해 셀 뻔했는데, 실제 온보딩은 항상 여러 개를 한 번에 고르고 다른 동작은 하나만 고른다는 차이로 구분했다.
